# 📊 Nexora Sales Performance Dashboard

![Dashboard Cover](dashboard-cover.png)

## 📌 Project Overview

This project is an Excel-based Sales Performance Dashboard created to analyze sales data and provide business insights through interactive visualizations, Pivot Tables, Charts, KPIs, and Slicers.

The dashboard helps track sales performance, product trends, salesperson performance, and city-level sales results.

---

## 🎯 Project Objectives

* Analyze sales performance using Excel.
* Create interactive Pivot Tables and Pivot Charts.
* Build a professional dashboard for decision-making.
* Monitor key business metrics through KPI cards.

---

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Dashboard Design

---

## 📈 Dashboard Features

* Total Sales Analysis
* Product Performance Analysis
* Sales by Country
* Sales by City
* Monthly Sales Trends
* Interactive Filters (Slicers)

---

## 📊 Key Performance Indicators (KPIs)

* Total Sales
* Total Quantity Sold
* Total Products
* Total Salespersons

---

## 📉 Pivot Table Analysis

The dashboard includes:

1. Product vs Total Sales
2. Country vs Total Sales
3. City vs Total Sales
4. Monthly Sales Analysis
5. Salesperson Performance Analysis

---

## 💡 Business Insights

* Identify top-performing products.
* Track sales trends over time.
* Compare city performance.
* Evaluate salesperson productivity.
* Support data-driven business decisions.
